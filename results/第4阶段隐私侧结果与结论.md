# FedVLA 第 4 阶段（隐私侧）结论：上行更新泄漏的是**动作标签**而非视觉观测；客户端级 DP 在此模型规模上"效用尽毁、隐私不保"

> 生成时间：2026-11-08 ｜ 实验台：异构划分 + MoE + 簇感知聚合（P3-C，`global_r49`）
> 威胁模型：诚实但好奇的服务器；攻击者拿到**被 DP 噪声污染后的**上行更新
> 攻击方法：DLG（Deep Leakage from Gradients），随机初始化，逐通路分别优化

---

## 一、一句话结论

FedVLA 的上行更新（trunk + normalizer + modalities_tokens）**泄漏的是客户端的私有动作序列**，
而不是视觉观测：攻击者能从 17.1M 维的共享主干梯度里把 8×4 的动作块**近乎完整地还原**
（余弦 0.97，rel_l2 0.24），却**完全无法还原视觉特征**（逐 patch 相关 0.03）。
更糟的是，**客户端级 DP 在这个模型规模上无法同时满足效用与隐私**：
噪声小到还能学习时（σ=1e-4）攻击几乎不受影响（cos 0.971 vs 无噪声 0.970）；
噪声大到开始伤害攻击时（σ=1e-2），共享主干的学习信号保真度已跌到 **0.024**——训练本身先废了。

## 二、三个必须先讲清楚的架构事实（全部实测，非推测）

### 2.1 反演目标是 ResNet 特征图，不是像素

Meta-World 的 zarr 里 `image` 存的是 **ResNet 提取的 512 维特征**：

| 证据 | 内容 |
|---|---|
| zarr 数组 | `image (7204, 1, 49, 512) float32`，取值范围 **[0, 15.77]** |
| stem 权重 | `stems.<d>_image.net.0.weight` = **(128, 512)** ⇒ image MLP 输入维 512 |
| stem 结构 | `net: 512→128→256`，`cross_attention: 16 个可学习 token  attend  49 个 patch` |

⇒ 反演潜变量 x̂ 的形状是 **(1, 1, 49, 512)**（49 个 patch × 512 维），
**不能套用像素域的 sigmoid 参数化**，指标也要换成**逐 patch Pearson 相关**。
论文里"重建出来的图"因此是 **7×7 空间 patch 热力图**（对 512 通道取均值），不是照片。

### 2.2 语言通路在本配置下不存在

实测 `policy.modalities = ['image', 'state']`，`cfg.stem` 无 language 键，
且在 eval 模式（关 dropout、前向确定性）下：

```
loss(无语言) = 0.26731178
loss(有语言) = 0.26731178
|Δ|          = 0.000e+00
```

HPT 的 T5 语言嵌入（zarr 里 `language (N, 16, 768)`）**根本没有被策略消费**。
⇒ 本文的模态敏感度分析覆盖 **视觉 / 状态 / 动作** 三通路，论文如实写明，
不虚构"语言通路"。

### 2.3 上行里没有"模态专属"的共享参数

`aggregate.py` 的 `_is_shared_param` 口径：上行 = `trunk.*` + `normalizer.<domain>` +
`modalities_tokens.*`，而 `stems.*` / `heads.*` 是**个性化参数、留在本地**。
实测各组在上行里的构成：

| 组 | 张量数 | 参数量 | 是否上行 |
|---|---|---|---|
| shared（trunk 主体） | 368 | 17.1346M | ✅ **唯一的大通道** |
| state（normalizer.state + modalities_tokens.state） | 11 | 0.5669M | ✅ |
| action（normalizer.action + heads） | 10 | 0.1031M | ✅ |
| vision（stems.image + modalities_tokens.image） | 9 | 0.6273M | ❌ stems 不上行 |

另外：`modalities_tokens` 虽然 `use_modality_embedding: true`，但在 `preprocess_tokens`
里**从未被引用** ⇒ 是死参数、无梯度、不构成泄漏通道。

⇒ **架构性结论**：FedVLA 把模态专属参数挡在设备内，服务器唯一能拿到的大通道是
**模态无关的共享主干**。这既是隐私上的天然优势，也直接决定了 DP 预算分配的
作用方式（见第五节）。

## 三、逐通路敏感度（消融法）

**方法**：把某一条通路的输入换成**另一条轨迹**的输入（其余保持真实），重算梯度 g_m，
定义两个互补指标：

- **相对变化** `D_m = ‖g_full − g_m‖₂ / ‖g_full‖₂`（幅度变化）
- **方向泄漏强度** `1 − cos(g_full, g_m)`（方向变化，∈[0,2]；0 = 完全不依赖该通路）

⚠️ donor 必须**跨 episode**：zarr 里 7204 步 = 100 集 × ~72 步，
**相邻索引是同一条轨迹的相邻时间步**，动作几乎相同 ⇒ 用 `idx+1` 会测出 D_action = 0（假零）。

| 通路 | D_m（幅度） | 1−cos（方向泄漏） |
|---|---|---|
| **动作（标签）** | 2.24 | **1.358** ← 最强 |
| 视觉（输入） | **3.82** | 0.760 |
| 状态（输入） | 1.76 | 0.136 |

**关键洞见：敏感度 ≠ 可攻击性。**
视觉通路让梯度的**幅度**变化最大（3.82 倍），但**方向**仍保留 24% 重合；
而动作通路让梯度的**方向几乎完全翻转**（cos = −0.358）。
对攻击者而言，"方向里编码了什么"才是信息量 ⇒ **动作才是真正的泄漏通道**。

## 四、梯度反演攻击：什么能被还原，什么不能

攻击设定：服务器只拿到 **trunk 梯度**（368 张量 / 17.135M 参数），用 DLG 联合优化候选
潜变量与候选动作，使候选上的 trunk 梯度与观察到的梯度方向一致。

**两个实现上的硬约束（踩过的坑）**：

1. **梯度匹配必须取 key 交集**。MoE 的 top-k 路由**随输入变化** ⇒ 候选前向的梯度张量集合
   是服务器收到的梯度集合的真子集（实测 15.82M vs 17.13M，差 1.32M）。
   服务器只收到"被激活专家"的梯度，攻击者自然也只能用交集。
2. **注意力必须走数学后端**。PyTorch 默认的
   `aten::_scaled_dot_product_efficient_attention` **没有二阶导实现**，
   DLG 的 `create_graph=True` 会直接崩。必须全局关掉 flash / mem-efficient。

**结果（随机初始化，即诚实攻击者：他只有梯度，不知道这条样本的内容）**：

| 反演目标 | 潜变量维度 | 无噪声重建 | 随机基线 | 结论 |
|---|---|---|---|---|
| **动作序列** | 32 | **cos 0.970 / rel_l2 0.24** | 0.000 | ✅ **近乎完整还原** |
| 状态向量 | 39 | cos 0.185 / rel_l2 3.70 | 0.000 | ❌ 失败 |
| 视觉特征图 | 25088 | corr 0.027 / rel_l2 1.31 | 0.001 | ❌ 失败 |

### 4.1 为什么动作能被还原、观测不能？—— 标签 vs 输入

动作和状态的潜变量维度相近（32 vs 39），结果却天差地别。原因是**泄漏路径的长短**：

- **动作是"标签"**：它直接进入 loss 的残差项，`∂L/∂features ∝ (pred − y)`。
  标签的信息沿着最短路径流进梯度，**信号集中、方向明确** ⇒ 32 维的欠定问题被轻易解出。
- **视觉/状态是"输入"**：它们要穿过整个 17.1M 维共享主干才能影响 loss，
  在梯度的 17.1M 维里留下的痕迹被彻底稀释 ⇒ 高维欠定问题无法求解。

⇒ **上行梯度泄漏的是标签，不是观测。** 这与梯度反演文献的经典结论一致，
但在 VLA 场景下有一个重要推论：**只要策略用动作做监督，客户端的私有动作就必然泄漏**。

### 4.2 视觉反演失败是"维度诅咒"，不是"优化不足"（对照组）

为排除"步数不够 / 学习率不对 / 匹配集选错"的解释，做了 4 组对照：

| 组 | 匹配集 | 步数 | lr | match loss（攻击目标） | rel_l2（重建误差） |
|---|---|---|---|---|---|
| V1 | dense | 300 | 0.05 | → 0.0068 | **1.3168** |
| V2 | dense | 300 | 0.01 | → 0.0068 | **1.3168** |
| V3 | all（368 张量） | 300 | 0.05 | → 0.0015 | **1.3142** |
| V4 | dense | 600 | 0.05 | → 0.0015 | **1.3168** |
| — | — | — | — | 随机基线 1.0 | 1.0 |

攻击目标被优化到 **match loss < 0.002**（比随机低 3 个数量级），**但重建误差始终钉在
rel_l2 ≈ 1.31**。⇒ 梯度映射存在**大量退化解**：不同的 x̂ 给出几乎相同的梯度。
视觉观测在共享主干的梯度映射下**不可辨识**，这是 17.1M 维共享主干带来的维度诅咒，
**与算力或优化超参无关**。

## 五、DP 预算与 H3：等总预算下的两套分配

### 5.1 为什么自变量必须是 σ 而不是 ε

trunk 有 17.1M 参数，客户端级 DP 的噪声总范数 = σ·C·√17.1M = **σ·4139**（C=1）。
若 σ=1（对应 ε≈1），噪声范数 4139 远大于裁剪后的信号范数 1 ⇒
**任何 ε∈[1,32] 的配置都落在噪声地板上**，"ε 越大越容易被反演"的规律根本画不出来。
真正的转折在 **σ≈1e-4**（对应 ε≈1e5~1e9）。
⇒ 论文的横轴用 **σ（对数刻度）**，并在标注里给出对应的 ε。

### 5.2 两套分配的定义（总 ε 相同）

并行组合语义（各组参数互不相交）：总 ε = **max_m ε_m**。

- **uniform（统一预算）**：所有组同一个 σ。
- **modality（模态感知）**：ε_m = ε_total · w_m / w_max，
  先验敏感度权重 w = {vision 0.50, state 0.15, action 0.10, shared 0.25}。
- **modality_rev（按实测可攻击性重分配，事后分析）**：
  w = {action 0.50, vision 0.30, state 0.10, shared 0.10}，
  依据是第三节测到的方向泄漏强度排序 action > image > state（**与先验假设相反**）。

同一个 σ_ref 下，两套方案的**总 ε 完全相同**（已写成单元测试断言）⇒ 对比是等预算的。

### 5.3 组合语义口径的敏感性（必须诚实说明）

H3 的结论**依赖 DP 的组合口径**，论文必须写清楚：

- **口径 A（max 在全部本地组上取）**：锚点是不上行的 vision 组 ⇒
  外传的 shared 只拿 0.5·ε_total ⇒ **σ_shared 比统一预算大 1.41×** ⇒ 对实际泄漏通道保护更强。
- **口径 B（max 只在上传组上取）**：锚点是 shared ⇒ 模态感知与统一预算
  **对 trunk 完全等价** ⇒ H3 不成立。

本文采用口径 A，理由是：**DP 保护的对象是客户端的私有数据，而不是"已经离开设备的东西"**。
stems/heads 是客户端私有的个性化参数（编码了本地数据），DP 噪声加在它们上保护的是
本地训练过程的隐私；把总预算锚在不上传的组上，就能"免费"收紧真正外传的共享主干。
同时本文**同时报告两者的效用代价**，让读者自行判断。

## 六、隐私-效用的完整权衡（本章最重要的表）

见 `privacy_table.md` 与 `privacy_budget_table.md`。核心读数：

- **σ 越小（噪声越弱）**：共享主干学习信号保真度 cos(干净, 加噪) 越接近 1，
  但动作重建 cos 也越接近无噪声值 ⇒ **隐私预算形同虚设**。
- **σ 越大（噪声越强）**：保真度断崖式下跌（σ=1e-2 时 shared 保真度已仅 **0.024**），
  而动作重建**下降很慢**（σ=1e-2 时仍有 0.93）。
- ⇒ **客户端级 DP 在 FedVLA 上是"效用尽毁、隐私不保"的最坏组合**：
  在有用的 ε 区间内，保护不了动作泄漏；而把噪声加到能保护动作的程度，联邦学习本身已经失效。

## 七、局限与诚实记录

1. **效用侧是代理指标**。本章用"共享主干学习信号保真度"cos(干净梯度, 加噪梯度) 代替
   任务成功率，因为它无需跑 MuJoCo 评估即可大规模扫描。代价：它衡量的是**上行更新里
   学习信号被破坏的程度**，不等于任务成功率。**这是本章最需要补强的地方**。
2. **反演攻击只覆盖 DLG**。没有对比 GradInversion / iDLG 等更强攻击者，
   所以"动作被完整还原"是**下界**（真实泄漏可能更严重）。
3. **样本量**：隐私侧用 3 个样本 × 200 步 DLG，没有做多 seed 显著性检验
   （通信侧是 3 seeds × 20 rollouts）。趋势方向清晰，但绝对值需谨慎解读。
4. **语言通路缺席**（见 2.2），三通路而非路线图原设的四通路。
5. **DP 施加在"客户端本地全部参数"上**，服务器观察其 trunk 子集；
   若只对上行的共享部分加噪，则上行里只剩一个模态组，"模态感知"在 FedVLA 上是空的。
