# 选题方向自测表

> 使用方式：按顺序填完四部分。第三部分出现任何一项 0 分，先停在这一项上补材料，不要往下走。
> 表中 `AUTHOR_INPUT_NEEDED` 为需要你本人或导师确认的内容，我不会替你填。

## 第一部分：三圈交集（先做减法）

一个能做完的选题，必须同时落在三个圈里。缺哪个圈，就会以对应的方式失败。

| 圈 | 判断问题 | 缺了会怎样 |
|---|---|---|
| 能做 | 数据/文本/样本/实验条件我拿得到吗？方法我会用或来得及学吗？时间够吗？ | 中途卡死，写到方法章才发现做不动 |
| 该做 | 导师认这个方向吗？学科内算正经问题吗？学校允不允许这个类型（有的学校不收纯综述、有的要求实证）？ | 开题被否，或答辩时被质疑"这不算是研究" |
| 想做 | 我能不能撑到写完？是真正的兴趣还是一时好奇？ | 写到第二章失去动力，拖到 deadline |

**填写区**

- 能做：________________________________
- 该做：________________________________
- 想做：________________________________
- 三圈交集处剩下的东西：________________________________

## 第二部分：四层收敛（把领域收成题目）

依次加限定词，每加一层就做一次检验，过不了就回到上一层换个切法。

| 层级 | 要加的东西 | 例子 | 检验 |
|---|---|---|---|
| 领域 | 大范畴 | 数字经济 / 明清小说 | 导师是否做这块，有无课程基础 |
| 方向 | 切入维度 | 直播电商中的主播话术 | 能否检索到足够的近五年核心文献 |
| 问题 | 关系或机制 | 话术如何影响冲动购买 | 答案是否非显而易见、有无争议空间 |
| 题目 | 边界条件 | 以某校大学生为样本 | 一句话主论点写不写得出来 |

**收敛公式**

```
研究对象（谁/什么）+ 切入维度（哪个角度）+ 关系（影响/机制/比较/评价）+ 边界条件（时间/地域/群体/数据范围）
```

**填写区**

- 我的领域：________________________________
- 我的方向：________________________________
- 我的问题：________________________________
- 我的题目：________________________________

## 第三部分：五道闸门打分（关键）

列出 3 个候选方向，每项按 0 / 1 / 2 打分：0 = 明显不行，1 = 勉强或待确认，2 = 没问题。

| 闸门 | 判断标准 | 候选 A | 候选 B | 候选 C |
|---|---|---|---|---|
| 可答性 | 在给定字数和时间内，用可得材料能回答吗 | | | |
| 可争议性 | 有没有"不是显而易见"的地方？人人都知道的答案没有论文价值 | | | |
| 资料可获得 | 核心文献、数据、样本能不能真正拿到（最常被低估的一项） | | | |
| 方法匹配 | 现有方法够用吗，或能在期限内学会吗 | | | |
| 规模匹配 | 不会大到做不完，也不会小到撑不起字数 | | | |
| **合计** | | | | |

**判读规则**

- 总分 ≥ 7 且无 0 分项 → 可以进入下一步（检索式 + 提纲）
- 出现 0 分 → 这一项是硬约束，先解决它再谈其他。资料拿不到就换方向，方法不会就换方法
- 两个候选分数接近 → 优先选导师能指导的那个，指导质量的影响大于题目本身的细微差别

## 第四部分：红线信号（命中即换方向）

- 检索不到足够的核心文献 → 要么太新（无研究基础），要么太冷（可能无价值或导师不支持）
- 需要的数据拿不到（内部数据、付费库、伦理审批未通过）
- 题目里写着"研究""分析""探讨"，但说不出具体机制 → 这还是一个领域，不是一个问题
- 创新点只能写成"前人没有研究过 X" → 通常是因为 X 不重要，而不是因为没人想到
- 一句话主论点写不出来 → 方向还是一团雾，别急着动笔
