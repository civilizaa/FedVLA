# 方向抉择备忘：回到 RIS 还是做联邦 VLA

> 写给你在焦虑时回来看。结论先行，理由在后。

## 一句话结论

**做联邦 VLA，配一条熔断线。** 理由不是它更容易，而是判断标准变了。

## 0. 最新约束更新（2026-10-09）

三条新信息，每一条都降低了联邦 VLA 的风险：

1. **RIS 也是纯仿真** → "学校不接受纯仿真"这个一票否决项解除。委员会本来就接受仿真论文。
2. **答辩委员会以通信为主** → 学科归属有明确答案：通信侧必须写厚，机器人侧是应用载体。
3. **不要求论文等级** → 不需要顶会级创新，**满足硕士论文四条硬门槛即可**（创新点、系统性对比、消融、统计）。这也意味着负面结果（比如验证"EDA 退化为 FedAvg"）可以直接作为贡献，没有发表压力。

结论：**联邦 VLA 的毕业风险从"中"降到"中低"**，推荐力度加强。剩下的风险集中在工程实现，而工程风险有熔断线兜底。

## 判断标准不是"哪个更容易发论文"

你的目标是毕业后转机器人。那么唯一有意义的比较是：
**两年后求职时，你希望简历第一行写什么？**

- 回到 RIS → 第一行是「RIS / 通信物理层」，面试官看到的是通信背景，机器人岗位不会因为一篇 RIS 论文认为你会做机器人学习。
- 联邦 VLA → 第一行是「VLA 微调 / 模仿学习 / MuJoCo / 联邦具身智能」，这是具身智能岗位正在招的东西。

如果只求稳稳毕业、不需要这两年积累转行资本，那 RIS 是合理选择。但那样的话，你要清楚自己主动放弃了什么。

## 一个必须识破的伪交叉

有人会建议："做 RIS 辅助机器人通信/定位，不就交叉了吗？"

那是**通信式交叉**——主体还是 RIS，机器人只是应用场景。你学到的仍然是信道建模与优化，**拿不到机器人学习栈**。面试官不会因为题目里出现"机器人"三个字就认你会做机器人。

真正有用的是**机器人式交叉**：主体是机器人学习（VLA、模仿学习、仿真评估），通信是你比别的机器人学生多一把的工具。这也是本方案把机器人侧放在 60%、通信侧放在 40% 的原因。

## 两条路的对比

| 维度 | 回到 RIS | 联邦 VLA |
|---|---|---|
| 上手 | 1 周，零环境风险 | 1–2 个月，前期几乎没产出 |
| 毕业风险 | 低，方向对口 | 中，靠第 3 章系统模型兜住学科归属 |
| 转行资产 | 几乎为零 | 机器人学习全栈 |
| 创新空间 | 领域拥挤，容易做成换目标再水一篇 | 方向新，已挖到两处空白 |
| 最坏情况 | 顺利毕业，但两年没积累转行资本 | 降级为复现与分析型，仍可毕业 |

## 熔断线：把"选错"的代价限定在一个月

纠结的根源通常是怕选错。那就别追求"选对"，去追求"选错的代价可控"。

**具体机制**：给第 1 月设一个硬判定点。

- **判定时间**：开始后第 4 周结束
- **判定标准**：MuJoCo + Meta-World 是否已装好，且 HPT 的 `train_test_metaworld_1task.sh` 能否跑通并产出可用的成功率
- **通过**：继续联邦 VLA
- **不通过**：转回 RIS。此时只损失 1 个月，而你本科做过 RIS，剩余时间完成一篇 RIS 硕士论文来得及

有了这条线，做联邦 VLA 的下行损失是有限的、已知的，而 RIS 路线的下行损失是"两年没有转行资本"——后者才是真正不可回收的。

## 决策前必须先确认的硬门槛

**已解除**：纯仿真这条不必再担心（RIS 本来也是仿真，委员会默认接受）。

还需确认两条（问教务和师兄）：

- 盲审评阅人是否也以通信学科为主（与答辩委员会一致的话，下面第 7 节的讲述原则照做即可）
- 是否有字数、图表数量、参考文献篇数的硬性要求（各校差异大，越早知道越好）

## 7. 面向通信委员会的三条讲述原则

委员会是通信的，他们不会用机器人学的标准评判你，但会因为看不懂而更苛刻。所以论文要写得让通信背景的人能自明。

### 7.1 最好用的一条：图的横轴选通信参数

| | 横轴 | 纵轴 | 效果 |
|---|---|---|---|
| **推荐** | 丢包率 / 信噪比 / 压缩比 / 隐私预算 ε | 任务成功率 | 一张图同时说服两个学科 |
| 避免 | 训练轮数 | 任务成功率 | 通信评委看不到自己的问题 |

这几张图是整篇论文的门面：**横轴是通信变量，纵轴是机器人指标**，两边都认。

### 7.2 把成功率当因变量，不是研究对象

论文的研究问题是"无线与隐私约束下联邦聚合是否有效"，**成功率只是衡量它的尺子**。

这样写还有一个额外好处：回避了"你没有真机、绝对成功率不高"的质疑——你的贡献是**相对增益**（你的方法 vs FedAvg vs EDA），不是绝对数值。在实验设置里明确写一句：所有方法在同一框架、同一骨干、同一数据下比较，绝对成功率不是本文贡献。

### 7.3 系统模型与相关工作按通信论文规范写

- 第 3 章要有符号表、假设列表、优化问题的形式化表述——这是通信评委最先翻的地方
- 第 2 章的相关工作以**联邦学习 over wireless、差分隐私、梯度反演攻击、隐私预算分配**为主线，VLA 与机器人文献单列一节作为应用背景
- 题目措辞偏通信：
  - 推荐《无线网络中联邦视觉-语言-动作学习的聚合策略与隐私保护研究》
  - 避免《基于专家混合的机器人操作策略研究》——学科归属悬空，容易被质疑

### 7.4 工作量配比不变，变的是呈现重心

工作量仍是机器人侧 60%、通信侧 40%（那是你真正学到的东西）；但**论文里的讲述重心要往通信侧压**：第 3 章加厚，无线与隐私实验升为主实验而非补充实验。

工作量是你学到的，呈现是给评委看的——这两件事可以不一样。

## 还有两种情况下应该回 RIS

1. **你无法接受前两个月几乎没有产出**——这个心理成本是真实的，装环境阶段看不到进展会很难熬，且你是放养状态，没人给你打气。
2. **找不到任何能帮你 review 机器人部分的人**——放养 + 完全陌生的领域，出错了没人纠正，风险会明显放大。至少要在网上找到一个能讨论的社区或师兄。

## 如果决定做，第一件事

不要先写方案，先去把 HPT 仓库的 `experiments/scripts/metaworld/train_test_metaworld_1task.sh` 跑通。这一个动作能同时回答三个问题：环境能不能装起来、8GB 显存够不够、你喜不喜欢这类工作。

跑通之后再回来细化方案，比现在纠结有用得多。

## 8. FL 还是 SL：最终建议（FL 主线，SL 做增量）

**结论：Split Learning 不换主线，作为第 5 章的一节或扩展实验，增量成本约 2 周。**

### 8.1 决定性理由：两者的失败模式不一样

| | 联邦学习做砸了 | Split Learning 做砸了 |
|---|---|---|
| 表现 | 增益不明显（你的方法 ≈ FedAvg） | 训练不收敛、损失抖动、激活爆炸 |
| 能不能写进论文 | **能**。H1 的可证伪设计把"EDA 在均衡划分下退化为 FedAvg"变成正面结论 | **不能**。不稳定是纯亏损，评委只会认为方法有问题 |
| 你的处境 | 已备好熔断线与 Plan B | 多花 3-4 周纯工程，且这部分不产生创新点 |

在 8GB 显存 + Windows + 六个月 + 放养的组合下，要选**"失败也可交付"**的那个。这是压倒性的理由，比技术优劣更重要。

### 8.2 其余三条

- **工程税**：SL 要额外写切分、跨切分梯度回传、两端优化器解耦、staleness 处理，且训练稳定性调参是个无底洞。
- **基线**：FL 有 FedAvg / FedProx / FedAvgM / SCAFFOLD 现成可凑 4-5 条；SL 的基线少，好处是没人抢，坏处是对比难凑、评审可能质疑。
- **已有资产**：`fl_core.py` 已跑通，HPT + Meta-World 脚本直接可用，最低难度方案与三条假设都是围绕 FL 搭的——换主线等于推倒重来。

### 8.3 但 FL 有一个真实风险，必须在第 6 周验证

FL 每轮只传一次权重，**丢包与时延的影响会被多轮平均稀释**，很可能出现"丢包 20% 时成功率纹丝不动"的情况。一旦如此，你那张"横轴丢包率、纵轴成功率"的门面图就画不出来，通信故事立不住。

**判据（第 6 周做一次预实验）**：固定其他条件，扫描丢包率 0 / 5% / 10% / 20%，看成功率变化幅度。

- 变化 **> 5 个百分点**（明显超出 3 seeds 噪声带）→ FL 稳，继续。
- 变化 **< 2 个百分点**（落在噪声内）→ 通信不是瓶颈，此时才有必要认真考虑转 SL。

**不用转 SL 的补救办法**（优先试这两个）：

1. 把压缩做到极端：1-2 bit 量化、top-1% 稀疏化，画"**压缩比 vs 成功率**"曲线——这是 FL 里最稳的通信图。
2. 设**上行流量预算**：固定总预算（如 2 GB），比较各聚合策略在预算内的收敛速度。这比丢包更敏感，也更贴近工程实际。

### 8.4 折中方案与时间点

主线走 FL；**第 8-10 周**（FL 跑通、数据管线与评估脚本稳定后）用同一套模型与数据加一个 SplitFed 变体作为第 5 个对比方法，约 2 周。此时复用度高，只新增切分与梯度回传。

收益：通信味道更足（激活压缩、丢包断链、特征反演三张图），且 SL + VLA 这块 scoop 风险低，等于给论文加了一层保险。

### 8.5 什么情况下应该反过来，选 SL 做主线

- 第 6 周判据显示通信损伤对 FL 确实无影响，且 8.3 的两个补救也出不来曲线；
- 或你明确想把第 3 章写成"切分点 × 压缩率的联合优化"这类更硬的通信优化问题。

不满足这两条，就别换。
