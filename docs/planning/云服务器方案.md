# 云服务器路线：把实验搬到 GPU 云

> 适配：已决定不用本地 WSL2，改用 GPU 云实例（AutoDL / 恒源云等）。
> 前提：本地 Windows 保留用于写论文、看图、整理表格。

---

## 0. 一句话

云服务器和 WSL2 **确实是两条路**，但差别比"在哪跑"更大——云上是原生 Linux，比 WSL2 少掉一堆坑，而且显卡从 8GB 变成 24GB，你可以把统计做得比原计划更扎实。

---

## 1. 两条路的真实差别

| | WSL2（本地） | GPU 云 |
|---|---|---|
| Linux 类型 | WSL2 里的 Ubuntu | 原生 Ubuntu 20.04/22.04 |
| 文件系统 | **跨文件系统 IO 慢一个数量级** | 没有这个问题 |
| 编译 mujoco-py | 慢且易出错 | 顺畅 |
| GPU | 你的 8GB 卡 | 3090/4090 24GB |
| 环境要装几次 | 1 次 | 1 次（但随时可能被重置，见第 6 节） |
| 切换/断连 | 零 | 需要 SSH，可能断 |
| 成本 | 0 | 约 100–200 元（全部实验） |
| 本地还能干嘛 | 训练时电脑被占 | **训练时本地完全空闲，可以写论文** |

最后一行对放养状态的你价值很大：训练挂在云上跑，你本地继续写第 3 章，两边不打架。

**选了云路线，VMware 和 WSL2 就都不用装了。** 本地 Windows 只需要能开浏览器、VS Code、SSH 客户端。

---

## 2. 选型与成本

| 平台 | 3090 24G | 4090 24G | 备注 |
|---|---|---|---|
| AutoDL | ≈1.5–2 元/时 | ≈2.3–3.5 元/时 | 按秒计费，关机不计费；学生最常用 |
| 恒源云 | ≈1.6 元/时 | — | 有竞价实例，低至 ≈0.3 元/时 |
| 阿里云 / 腾讯云 | — | 2.4–2.6 元/时 | 企业向，个人无折扣，库存紧张 |

价格随行情浮动，**以官网实时价为准**。

**建议：先租 3090 24G。** 你的模型只有 12.6M，3090 完全够；等确认要放宽实验规模（更多 seeds、更大 batch）再升 4090。

**镜像选择**：`PyTorch 2.x + Python 3.10 + CUDA 12.1` 这类预装镜像，自带 conda 和 CUDA 版 torch，能省掉半小时。

**先充 100 元。** 全部实验估计 100–200 元，用不完可以退。

---

## 3. 无卡模式：这条路线省钱的核心

AutoDL 有"无卡模式开机"（其他平台叫关机保留/低价保活），**只按存储计费，约 0.1 元/时**。

所有不烧算力的活都在无卡模式做：

- 上传代码、git clone
- 装环境（`bash setup_cloud.sh`）
- 下载 HPT 权重、Meta-World 数据
- **写代码、改 bug、跑单元测试**

只有真正要跑训练时，才切到有卡模式；跑完立刻切回去或关机。

**这一招能省掉 95% 的云费用。** 你大部分时间本来就在写代码和改 bug，不是在训练。

---

## 4. 连接方式

1. 实例创建后，详情页会给一条 SSH 登录命令（形如 `ssh -p 12345 root@region-1.autodl.com`），先设好密钥或记住密码
2. 本地 Windows 装 **VS Code + Remote - SSH 扩展**
3. VS Code 里 `Ctrl+Shift+P` → `Remote-SSH: Connect to Host`，填上面的地址
4. 连上后打开云上的项目目录，**终端、文件树、Python 解释器、调试全在云上**，界面还是 Windows 的

体验和本地开发几乎一样，且你写论文、拷图都在本地，两边天然分开。

> 快速验证阶段也可以先用 AutoDL 自带的 JupyterLab（网页版），确认环境没问题再切 VS Code。

---

## 5. 云上是原生 Linux，麻烦少一半

准备卡里那些 Linux 命令**原样可用**，而且：

- **没有 `/mnt/c/` 跨文件系统问题**——WSL2 上最烦人的那个坑直接不存在
- `mujoco-py` 编译更顺畅（云实例 CPU 核心多、磁盘快）
- 不需要配 `.wslconfig`、不占本地内存

但有一件事不变：**云服务器没有显示器，MuJoCo 离屏渲染仍然要配**。`MUJOCO_GL=egl` 不行就换 `osmesa`，两个都试一遍（`setup_cloud.sh` 已默认 egl）。

---

## 6. 一条命令装环境（setup_cloud.sh）

工作区根目录已放好 `setup_cloud.sh`，把准备卡里的步骤固化成了幂等脚本：系统依赖 → MuJoCo 210 → 环境变量 → conda → torch cu118 → HPT 依赖子集 → 自检。

```bash
# 无卡模式下执行
git clone <你的仓库> && cd <仓库>
bash setup_cloud.sh
```

**为什么云路线比本地路线更依赖这个脚本**：云实例随时可能被重置或过期，环境重建只要 20 分钟，你就不会心疼；而且这个脚本本身就是论文"可复现性"的资产，附录里直接引用它。

注意脚本第 5 步会检测镜像是否已带 torch 2.1.1，**带了就跳过**，避免覆盖镜像自带版本导致 CUDA 不匹配。

---

## 7. 持久化：这条路最大的风险

**云实例的系统盘不是你的硬盘。** 重置、过期、误操作都会清空它。三条对策，缺一不可：

| 什么 | 放哪 | 频率 |
|---|---|---|
| 代码 | **GitHub 私有仓库** | 每次改动立刻 push |
| 数据集、模型 checkpoint | 云的数据盘 / 文件存储 | 训练产出即时写过去 |
| 实验日志与结果 | 每周打包下载到本地 Windows | 每周五 |

**绝不要把 6 个月的实验成果只存在云上。** 这条比省钱重要得多——真丢了，重跑的成本远高于几块钱存储费。

建议在仓库里加一个 `.gitignore`，把 `output/`、`data/`、`*.ckpt` 排除，代码只 push 代码。

---

## 8. 24GB 显存的真实收益：把统计做扎实

这是云路线比本地 8GB 最大的好处。原计划受显存限制的地方，现在可以放宽：

| 项 | 原计划（8GB） | 云上（24GB） |
|---|---|---|
| seeds | 3 | **5**（统计更有说服力） |
| batch | 16 | 32 |
| 任务数 | 3 | 5 |
| rollouts | 20 | 30–50 |
| 客户端数 | 4 | 8 |
| 主干 | HPT-Base 12.6M | 仍用 Base，或试 Large 50.5M |

**但不要一次全放开。** 先按原配置跑通全流程，然后每次只改一项，记录它对结果和耗时的影响——这本身就是论文里"实验设置"和"敏感性分析"的素材。

**seeds 从 3 加到 5，是性价比最高的一项**：硕士论文"统计充分性"这条硬门槛，5 seeds 明显比 3 更有底气，而成本只增加 2/3 的训练时间（大概几十块钱）。

---

## 9. 成本控制与断点续跑

**省钱**

- 无卡模式做所有非训练工作（见第 3 节）
- 训练用 `nohup ... > log.txt 2>&1 &` 或 `tmux` 挂后台，日志必须落盘
- 跑完立刻关机/切无卡——按秒计费，空转就是烧钱
- 写一个 `run_all.sh` 把一串实验串起来，睡前挂上，醒来收结果

**防断**

- 长任务用 `tmux`，SSH 断了会话还在
- 训练脚本每个 seed 存一次 checkpoint，断了不用从头跑
- 你的模型小、单次训练短（预计几分钟到十几分钟），**断了重跑的成本很低**，不必过度设计

## 10. 云路线的第 0 周重排

环境这条线的任务变了，比原计划短：

| 天 | 做什么 | 状态 |
|---|---|---|
| 第 1 天 | 注册 AutoDL、实名、充值 100 元 | — |
| 第 1 天 | 创建实例：3090 24G + PyTorch 2.x/Py3.10/CUDA 12.1 镜像 | — |
| 第 1–2 天 | **无卡模式**跑 `setup_cloud.sh` | — |
| 第 2 天 | 验证内置 Meta-World（HPT 自带，不用装，见下） | — |
| 第 2 天 | 跑通第 9 节的 1task 冒烟命令 | — |
| 第 3 天 | 建 GitHub 私有仓库，push 代码 | — |
| 第 3–4 天 | 测四个数：单 epoch 耗时、显存峰值、rollout 耗时、上传聚合耗时 | — |

**红线不变：第 3 周末跑不通 1task 训练命令，就启用 Plan B。**

注意云上测出来的"单 epoch 耗时"比本地 8GB 卡快很多，**排期要按云上实测重算**，不能沿用本地估算。

---

## 11. 三个风险与对策

| 风险 | 对策 |
|---|---|
| 环境被重置，重装要再踩一遍坑 | `setup_cloud.sh` 已固化；Meta-World 版本记进 `env_setup.md` |
| 成果只存在云上，丢了重跑 | 代码每天 push GitHub；结果每周打包下载本地 |
| 需要实名认证、绑定支付方式 | 早点办，别等要跑实验时卡住 |

---

## 12. 如果云路线也不顺

退路依次是：换一家平台（恒源云）→ 换镜像版本 → 回到本地 WSL2。**别在选平台上纠结超过两天**，环境装通比选哪家重要得多。
